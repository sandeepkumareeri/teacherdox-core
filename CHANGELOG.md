# Changelog

All notable changes are listed here. The project follows [Semantic Versioning](https://semver.org/);
the `.tdx` format has its own version (`spec_version`, currently 2.0.0).

## [0.1.0] — 2026-10-28

First public release, built during the Meta Global AI Developer Hackathon (see `HACKATHON.md` for the
day-by-day log).

### Format and trust layer
- `.tdx` 2.0 specification (`spec/tdx-2.0.md`) and normative JSON Schema 2020-12
  (`spec/schema/tdx-2.0.schema.json`), with a dependency-free validator.
- Reference implementation in `src/tdx` (no runtime dependencies): RFC 8785 canonical JSON, UUIDv7,
  Ed25519 keys with validity windows and revocation, capsule hash, draft → lock, per-educator daily
  hash chain, amendments, `verifyCapsule` / `verifyDay`, Merkle day seals and inclusion proofs,
  countersignatures, stable verification failure codes (spec §9).
- Conformance test vectors (`spec/vectors/`, published test key) generated by
  `scripts/make-vectors.js` and checked by both verifiers.

### Record Engine
- Capability router (`segment`, `transcribe`, `structure`, `check`) with priority order, fallback on
  error / timeout / unsupported input / consent / daily limit, and provenance per call.
- Providers: Meta Model API (SAM 3.1, Muse Voice Transcribe, Muse Spark), Muse Spark Open on Baseten,
  and a host-supplied fallback (`fromGenerate`, e.g. Gemini).
- Pipeline locate ∥ listen → read → check → score → schema-valid draft capsule; confidence routing to
  auto-lock / confirm / hold; nothing usable → held, never invented.
- Packs: locales en, ml, te, hi, pt-BR, id, fr (non-English are draft translations); six institution
  types; countries IN, BR, ID, FR, SN; policies personal, school_compliance, government_audit,
  low_connectivity.

### API, verifier, CLI
- REST API `/v1` on `node:http`: capture → durable queue → draft, lock / confirm / amend, countersign,
  day seal and proofs, export, public verification, telemetry; per-tenant bearer tokens.
- Browser verifier page (WebCrypto, independent second implementation, identical reports).
- `tdx` CLI: `verify`, `validate`, `hash`, `keygen`, `process`, `serve`.

### Evaluation
- `eval/` harness: 12 synthetic boards and 8 synthetic voice notes; per-field accuracy, latency,
  tokens and cost; results in `eval/RESULTS.md` from real GitHub Actions runs. On 20 synthetic cases:
  field accuracy Meta Model API 81%, Gemini 77%, Muse Spark Open 69%; boards 98% for each on the cases
  they answered; Meta weaker on Malayalam and Telugu voice notes.

### Project
- CI on Linux and Windows, strict JSDoc type check of `src/tdx`, coverage, CodeQL.
- `SECURITY.md` (threat model), `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `NOTICE`.
- Docs: `docs/quickstart.md` (Windows PowerShell and Linux) and `docs/how-a-record-is-born.md` (a real
  live run, reproducible signing with the published test key).
